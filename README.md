Six scenes. One scroll. Built end-to-end as a love letter to my own craft — and to anyone scouting for a software architect who treats the web like a stage.

**The Architect · The Forge · The Arsenal · The Journey · The Signal · The Exit**

Each section is its own React Three Fiber scene with custom GLSL shaders, GSAP-orchestrated motion, and a procedural Web Audio engine that plays in A-major while you scroll.
